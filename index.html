The uncertainty triangle, in motion.

A controller corrects the estimated state towards the nominal path; it cannot observe truth directly. This experiment removes that control problem by prescribing the nominal motion as truth.

Exact knot dynamics

h = 0.1 s · 50 intervals · z = 1 m

pk+1 = pk + hvk + ½h²ak + ⅙h³jk + ¹⁄₂₄h⁴sk

vk+1 = vk + hak + ½h²jk + ⅙h³sk

ak+1 = ak + hjk + ½h²sk

jk+1 = jk + hsk

ψk+1 = ψk + hrk + ½h²αk

rk+1 = rk + hαk

Snap s and yaw acceleration α are constant inside each interval, so these discrete dynamics are exact.

Estimation-aware programme

CasADi · IPOPT · warm-started continuation

minimise JP(X, U)

subject to Jmotion ≤ (1 + ε)Jmotion⋆

Jmotion = hΣ (‖sk‖² + 0.1αk²)

Jmotion⋆ is solved first. ε then grants a relative motion budget; there is no arbitrary covariance–motion weighting and no prescribed lateral waypoint or parallax reward.
